# Cryptography and Network Security Project

## Project Description

This project was developed for the ETTCS801 Cryptography and Network Security assessment.

The project demonstrates:

- Risk assessment
- File encryption
- File decryption
- SHA-256 integrity verification
- Error handling
- Network traffic filtering
- Firewall testing
